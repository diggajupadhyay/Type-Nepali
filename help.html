📖 How to Use Nepali Typing Extension

This extension allows you to type in Nepali on any website using English keyboard input.

✨ Features

  • Real-time transliteration from English to Nepali
  • Enable/disable the extension with a single click
  • Keyboard shortcut for quick toggling (Ctrl+Alt+N)
  • Over 300 common words cached for instant translation
  • Works on all websites and text fields
  • Customizable settings for font and behavior

🚀 How to Use

  1. Click on the extension icon to open the popup
  2. Click the On button to enable Nepali typing
  3. Navigate to any website with a text input field
  4. Start typing in English (e.g., "namaste")
  5. Press Space to convert to Nepali (e.g., "नमस्ते")

💡 Tips

  • Type common words like "namaste", "nepal", "dhanyabad" for instant translation from cache
  • The extension works in input fields, textareas, and contenteditable areas
  • Press Enter to start a new line without triggering translation
  • Visit the Settings page to customize your experience
  • Check the quick stats in the popup to see your translation activity

❓ FAQ

Does this work offline?
The extension has 300+ common words cached for offline use. For uncommon words, it uses Google's Input Tools API which requires an internet connection.
Will this work on all websites?
Yes! The extension works on all websites including Facebook, Twitter, Gmail, and any other site with text input fields.
Can I customize the font?
Absolutely! Visit the Settings page to choose from different font sizes and font families.
